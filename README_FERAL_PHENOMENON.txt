CRYPTOMON COMPENDIUM — CHAPTER V: THE FERAL PHENOMENON

INSTALL
1. Back up your current website ZIP or folder.
2. Copy app.js, feral.html, feral.css and feral.js into the same directory as index.html and catalog.js. Replace app.js when prompted. Do not nest these files in a new subfolder.
3. This patch assumes you already installed the World Atlas update. If not, install that update first, then this one.
4. Open index.html and select Feral Phenomenon in the top navigation or Chapter V in the Field Index. For a hosted site, upload the four files and hard-refresh (Ctrl+F5).

WHAT'S INCLUDED
- A classified Society research dossier about Feral alternate evolution, signs of corruption, three unconfirmed theories, open research questions and a field advisory.
- Interactive comparison of Fabled, Mythic and Feral forms for the 33 documented Feral families in the current catalog.
- Three archival case studies using existing dedicated Feral cryptographs and researcher notes (Wispit, Squonky, Kodaroot).
- Searchable Feral registry with affinity filters, live catalog counts and links to individual entries.
- New chapter navigation, a shortcut from Feral records and improved mobile navigation.

COMPATIBILITY
Built from the last World Atlas update's app.js and the 142-record catalog. The Atlas, previous lore refresh and collapsible Field Index are preserved. No individual entries, catalog.js, style.css, Atlas files or artwork are replaced. If you manually edited app.js, back it up before replacing it. The registry and family comparison read catalog.js directly, so future Feral entries following the current slug convention will appear automatically. The three selected case studies are archival snapshots and can be edited in feral.js.

CHECKS
Chromium DOM checks passed for all 33 Feral records, family comparisons, all six affinities, search/reset, index collapse, mobile width, Atlas's 142 records, previous lore and chapter link targets. All referenced assets and entry pages were checked against the complete archive. Direct browser navigation was blocked in the testing environment; live deployment and page-to-page navigation were not tested.
